# Sample ERC20 (Hardhat)

This project is a local Hardhat Solidity example with one ERC20 token contract.

## Requirements

- Node.js 18+

## Install

```bash
npm install
```

## Compile

```bash
npm run build
```

## Test

```bash
npm test
```

## Deploy (local hardhat network)

```bash
npm run deploy:local
```
