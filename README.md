# web3（Hardhat 合约）

本仓库为 **Hardhat 合约工程**。前端见独立仓库：<https://github.com/wanghaikui274973875/web3-dapp>

复制 `.env.example` 为 `.env`，填写 Sepolia RPC 与私钥（勿提交）。

```bash
npm install
npm run build
npm test
npm run deploy:local
npm run deploy:sepolia:permission
npm run deploy:sepolia:simple
npm run deploy:sepolia:memo
npm run deploy:sepolia:erc20
npm run deploy:sepolia:nft
```

Node.js 建议 18+。
